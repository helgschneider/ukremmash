# Электрик Помощник

Создай веб-приложение для управления заявками на ремонт электрики в небольшом посёлке. 

### Технологический стек и UI

- Фронтенд: React, Vite, Tailwind CSS, shadcn/ui.

- Иконки: Lucide-react.

- Таблицы и экспорт: xlsx (SheetJS) и jspdf / jspdf-autotable.

- Хранение данных (имитация или интеграция с Supabase): Локальное состояние (React state/localStorage) с простой ролевой моделью, готовое к подключению реальной БД.

### Авторизация и Роли

Начальный экран — форма входа по паролю.

1. Пользовательский пароль: "user123" (дает роль "User").

2. Административный пароль: "adоmin$123" (дает роль "Admin").

После успешного входа роль сохраняется, в шапке сайта отображается кнопка "Выйти".

### Интерфейс Пользователя (User)

После входа по умолчанию открывается вкладка/окно "Добавить заявку". У пользователя есть две вкладки:

1. "Новая заявка" (Форма добавления).

2. "Список заявок" (Таблица).

Поля формы добавления заявки:

- Улица (текстовое поле или выпадающий список)

- Номер дома (текст/число)

- Номер подъезда (число)

- Номер этажа (число)

- Номер квартиры (текст/число)

- Фамилия и Имя заявителя

- Телефон заявителя (с маской или валидацией)

- Суть заявки (textarea, текстовое поле для описания задачи)

При отправке формы автоматически фиксируются текущие дата и время создания.

Вкладка "Список заявок" для Пользователя:

- Отображает таблицу всех заявок с сортировкой по умолчанию от новых к старым (по дате добавления).

- Пользователь может редактировать или удалять только созданные им заявки (или любые, если это упрощенная локальная версия, но с возможностью редактирования основных полей).

### Интерфейс Администратора (Admin)

При входе под админом по умолчанию открывается "Панель управления" (список всех заявок).

Администратор имеет полные права:

1. Просмотр всех заявок в виде таблицы с сортировкой и фильтрацией по статусу.

2. Возможность редактировать любую заявку.

3. Дополнительные админ-поля при редактировании заявки:

   - Статус: выпадающий список ["В обработке", "Выполнено"].

   - Дата и время выполнения (datetime-local инпут, заполняется при переходе в статус "Выполнено").

   - Результат выполнения заявки (textarea, текстовое поле для отчета).

### Инструменты экспорта (Доступны и админу, и пользователю над таблицей)

1. Кнопка "Экспорт в Excel" — скачивает текущий список заявок в формате .xlsx с красивым форматированием колонок.

2. Кнопка "Экспорт в PDF" — генерирует документ .pdf с таблицей заявок, адаптированной под печать (альбомная или книжная ориентация, четкие границы).

### Дизайн и стиль

Стиль аккуратный, чистый и утилитарный (Tailwind/shadcn). Основной цвет — глубокий синий или профессиональный серый (Slate/Zinc). Интерфейс должен быть полностью на русском языке, адаптивным под мобильные телефоны (так как электрики или жители могут открывать сайт со смартфонов).
